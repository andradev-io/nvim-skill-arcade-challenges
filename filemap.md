# File map

- `CLAUDE.md` — agent instructions: stack, commands, conventions
- `README.md` — overview, how it fits together, safety model, local use, maintainer setup
- `CONTRIBUTING.md` — how to write a good challenge, fields, solution rules, how to test a draft
- `challenges/*.json` — published community challenges (file name = id)
- `schema/challenge.schema.json` — JSON schema of a challenge (editor help; the real gate is the plugin schema)
- `scripts/validate.lua` — headless Neovim: schema check + replay of every reference solution
- `scripts/build.lua` — same checks, then writes the `community.json` bundle that `:ArcadeSync` downloads
- `.github/workflows/validate.yml` — on PRs: Neovim replay of challenges; lint, typecheck, tests and build of the site
- `.github/workflows/pages.yml` — on main: tests, site build, bundle build, deploy to GitHub Pages
- `package.json`, `vite.config.ts`, `tsconfig*.json`, `eslint.config.js`, `index.html` — site toolchain and entry HTML
- `src/main.tsx` — React root: MUI providers and CSS layer order
- `src/App.tsx` — page: top bar, hero, workspace, published list
- `src/theme.ts` — MUI light/dark theme (andradev.io look: JetBrains Mono, olive accent)
- `src/index.css` — CSS layer order
- `src/core/types.ts` — `Challenge`, `Expect`, `DraftForm`, `State`
- `src/core/keys.ts` — Vim key tokens, key count, S/A/B/C key rank
- `src/core/compare.ts` — `linesEqual` / `check` (same end-state rules as the plugin), browser-checkable helpers
- `src/core/replay.ts` — approximate normal-mode interpreter for the reference-keys preview
- `src/core/track.ts` — track rules: checkpoint stepping in order, goal/untouched-map verdict, rules line
- `src/components/draft/TrackSection.tsx` — "Track" form section for `area: track`: clickable map editor, checkpoints, key rules
- `src/core/schema.ts` — form → challenge JSON, schema checks, safe-solution rules, PR link
- `src/core/roomCode.ts` — `ARC1.` room code encode/decode, `:ArcadeJoin` / `:ArcadeTry` command text
- `src/core/core.test.ts` — tests for keys, compare, replay, room code and schema
- `src/store/draftStore.ts` — zustand store of the form (saved to localStorage, fails soft)
- `src/hooks/useDraft.ts` — derived challenge, errors, JSON, room code and PR link
- `src/hooks/usePlay.ts` — one play round: key count, clock from the first key, end-state judging
- `src/hooks/useCommunity.ts` — fetches the published `community.json` once, fails soft
- `src/hooks/useClipboard.ts` — copy helper with feedback, file download
- `src/components/layout/TopBar.tsx` — brand, GitHub link, light/dark toggle
- `src/components/common/` — `Field` (store-bound input), `Row`, `Section`, `CodeBlock`
- `src/components/draft/DraftForm.tsx` — the three form sections
- `src/components/draft/ResultPanel.tsx` — validation result, JSON, copy / download / submit as pull request
- `src/components/play/VimEditor.tsx` — CodeMirror 6 + Vim emulation wrapper
- `src/components/play/PlaySession.tsx` — status bar, editor and buttons of one round
- `src/components/play/PlayPanel.tsx` — Play tab: notes, flags, round remount on change / Reset
- `src/components/join/JoinBox.tsx` — room code command and the file alternative
- `src/components/sim/SimCheck.tsx` — start-state verdict and reference-keys replay
- `src/components/published/PublishedList.tsx` — filterable cards of published challenges, "Open in terminal", "Use as template"
- `src/examples.ts` — ready-made drafts (first visit loads the first one; the picker loads the others)
- `src/pages/HomePage.tsx` — landing page: pitch, round preview, stats, features, install, community
- `src/pages/CreatePage.tsx`, `ChallengesPage.tsx`, `TerminalPage.tsx` — the other three pages (builder, published list, full-screen terminal with side menu)
- `src/hooks/useRoute.ts` — tiny hash router (`#/create` ...), no dependency
- `src/store/terminalStore.ts` — the buffer the terminal edits; other pages hand one over
- `src/components/terminal/KeymapSource.tsx`, `Statusline.tsx` — GitHub keymap loader + report, lualine-style bar
- `src/core/keymaps.ts` — scans Lua / Vimscript configs for keymaps (never executes): working maps, stubs that say what needs a plugin, skipped modes
- `src/components/terminal/themes.ts`, `src/store/themeStore.ts` — Terminal color themes (Catppuccin, Dracula, Tokyo Night, Gruvbox, Nord, One Dark, Rosé Pine) as CSS variables; choice remembered
- `src/components/play/languages.ts` — syntax highlighting per filetype (CodeMirror legacy modes, loaded on demand) and the colors
- `src/components/play/exCommands.ts` — ex commands the editor lacks: tabs/buffers, :m, :echo, quit and window no-ops, stub messages
- `src/core/github.ts` — source parsing (user, repo, file, URL), config file discovery and fetching from GitHub
- `src/pages/SupportPage.tsx` — what works / not, the user's config report, plugin request links
- `src/plugins/registry.ts` — supported / unsupported plugin list + detection by repo name
- `src/plugins/comment.ts`, `surround.ts`, `textobjects.ts`, `autopairs.ts` — pure logic of the plugin imitations (unit-tested)
- `src/plugins/vimGlue.ts` — operators, motions and key handling that plug them into the editor
- `src/store/pluginStore.ts`, `src/components/terminal/PluginList.tsx` — which imitations are on, and the sidebar list
- `src/store/keymapStore.ts` — loaded keymaps, persisted in localStorage
- `src/components/layout/Workspace.tsx` — one full-width workspace: sticky status + tab bar (Describe, Play, Check, Neovim, Submit), every panel stays mounted
- `src/store/uiStore.ts` — which workspace tab is open (hero buttons and tab bar share it)
- `src/components/draft/ExamplePicker.tsx` — chips that load an example or a blank form
- `worker/` — Cloudflare Worker + D1 score API (Keycloak JWT check, leaderboard); see worker/README.md
