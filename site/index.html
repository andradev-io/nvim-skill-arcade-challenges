Skill Arcade Challenges

Design a challenge for nvim-skill-arcade. A challenge is data: a start buffer plus the expected end state. Any key sequence that reaches it wins. Try it as you write it, here or in Neovim. Your reference solution is replayed by CI before anything is published, and no uploaded code is ever executed.
