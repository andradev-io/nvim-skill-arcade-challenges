Skill Arcade Challenges

Design a challenge for nvim-skill-arcade. A challenge is data: a start buffer plus the expected end state. Any key sequence that reaches it wins. Your reference solution is replayed by CI before anything is published, and no uploaded code is ever executed.

Result

    
      
    
        
        
        Submit as pull request
      
    
      
    "Submit" opens GitHub's new-file page prefilled with this challenge; GitHub forks the repo and opens a pull
      request for you. CI replays your reference solution (must fail at the start and pass after your keys) and a maintainer reviews it.
      If the link is too long for your browser, use Copy JSON and add challenges/<id>.json yourself.
    
    
    

    
    
      
    Published challenges
    
      
      
    
      
      
      
      In Neovim: :ArcadeSync downloads them. They join your runs and practice, marked as community.
